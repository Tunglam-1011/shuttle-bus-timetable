# 泰瑞府班车助手 UI 优化版

根据需求调整了排版顺序，并删去了乘车指南模块，整体界面更加清爽聚焦。

## 页面结构与排序
1. **顶部状态栏 (Hero)**：实时校车时钟与运行状态、深浅色模式切换、5分钟发车提醒。
2. **主标签页 (Page Tabs)**：
   - `实时班次` (默认激活，带经典高亮下划线)
   - `班次查询`
3. **控制面板 (Control Panel)**：
   - 路线方向切换：`泰瑞府 → 道远楼东` | `道远楼东 → 泰瑞府`
   - 上车站选择器（切换至返程时自动展开）：`道远楼东` | `张灵斌楼` | `综合教学楼`
4. **实时班次视图**：
   - 焦点发车大卡片（大字号时间、实时倒计时徽章、等待进度条、紧急脉冲警示）
   - 后续第 2、3 趟紧凑班次
   - 今日收车后友好提示次日首发时间
5. **班次查询视图**：
   - 日期类型与时段下拉筛选
   - 支持一键开关「仅显示尚未发车班次」
   - 一键定位到即将发车的班次
